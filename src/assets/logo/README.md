## Rules

  or component may import it directly. Shipping variants live under
  `src/assets/logo/variants/` (produced by **Task 24**) and as SVGs
  alongside this file (produced by **Task 25**).
- **Do not re-save through an image editor** — that would re-encode
  the JPEG and drift the SHA-256 above. If a variant is needed, cut it
  from a lossless intermediate, not from this file after re-export.
- **Do not move this file into `public/`.** `public/` is reserved for
  files referenced by `<link>` / `<meta>` tags (favicons, OG images
  produced by Tasks 26–27).
- **Do not delete the OneDrive original** — the repo copy is a mirror,
  not the archive.
